# Agent instructions

Read `CLAUDE.md` first: it holds the working rules for this repository,
including how to work with Sam (the site's owner, not a developer), the
pull-request and publish flow, and the recipes for text changes, reordering
clips, and adding a video from a Google Drive link. The technical reference is
`docs/developing.md`; the plain-language guide is `README.md`.

Cloud sandboxes: adding a video needs outbound network access (Google Drive
download, ffmpeg install). If the environment blocks it, say so plainly and
stop; do not fabricate outputs.
