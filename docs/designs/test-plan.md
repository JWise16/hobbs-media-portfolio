## Affected Pages/Routes
- /[theme] (hobbs, dark, light, twilight) — home: hero reel + plaque, scroll-dim, what I do, selected work stack, about, contact
- /[theme]/for/[agent] — calling card with personalized plaque; two-beat (reel → contact); unknown agent → 404
- /[theme]/p/[slug] — property calling card; reel override; address only if present; unknown → 404
- /[theme]/**/opengraph-image — per-route OG PNG with poster + wordmark + plaque line
- /robots.txt — noindex everywhere during review; home only indexable at SITE_STAGE=live

## Key Interactions to Verify
- iPhone: hero video playing (currentTime advances) within ~1 s of load on the three cinematic themes; hobbs shows still hero
- iPhone: scroll one viewport → overlay dims to ~0.86, wordmark lifts, sections cover the video (no peek-through)
- iPhone: selected work: exactly one <video> playing at any scroll position; posters visible before play; no tap needed
- iPhone: scroll back to top → hero re-attaches and plays
- Desktop (≥1024 px): hero src is the 1080 rung before first play; no restart flicker
- Tap "Text Sam" / "Email Sam" / Instagram → correct sms:/mailto:/https hrefs
- /for/jessica plaque shows "PREPARED FOR JESSICA · WINDERMERE"; scroll reveals contact + one quiet link to work
- Paste /dark/for/jessica into iMessage (manual): preview shows poster, wordmark, name

## Edge Cases
- Low Power Mode (real device, manual): poster stays, tap-to-play affordance appears; nothing errors
- prefers-reduced-motion: posters only, no dim animation, stack does not autoplay
- Tab hidden → all videos paused; tab visible → closest-to-center resumes
- JavaScript disabled: hero poster + 720 src present; page readable end to end
- Slow 3G throttle: no spinner, poster visible, no layout shift when video starts
- Unknown theme, agent, or property slug → 404 page, not redirect
- work[] empty → section hidden; properties[] empty → build passes
- Long agent displayName (40 chars) → plaque wraps, no horizontal scroll
- Rotate phone landscape → hero keeps focal crop, plaque still legible
- SITE_STAGE=live with todo() placeholders → build fails listing every label; without → passes

## Critical Paths
- Open review link on iPhone over cellular → reel plays → scroll dims → work stack plays one at a time → tap Text Sam
- Forward /for/[agent] link → rich preview → open → personalized plaque → contact
- Add a clip: manifest entry → `encode` skips unchanged, encodes new, writes index → clip appears in stack after deploy
- Launch: set SITE_STAGE=live → build refuses until placeholders confirmed → passes → home indexable, /for and /p noindex
